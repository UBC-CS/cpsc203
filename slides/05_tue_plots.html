Step 4: Reshaping for Plotting

Our data looks like this:

  • One row per song per week.
  • Multiple rows for each week.
  • Multiple rows for each song.
date title rank
2025-01-04 Song A 1
2025-01-04 Song B 15
2025-01-11 Song A 3
2025-01-11 Song B 1

But for plotting we want

  • One row per week (x-axis value).
  • One column per song (one line).
  • Rank is no longer a column.
date Song A Song B
2025-01-04 1 15
2025-01-11 3 1

Pivoting is a very common operation on tabular data.

  • The unique entries in one input column (or perhaps a combination of input columns) become the rows of the output.
  • The unique entries in another input column (or perhaps a combination of input columns) become the columns of the output.
  • Some aggregation of the entries in yet another column (or perhaps a combination of input columns) for the matching rows become the entries of the output.
  • This case is a particularly simple pivot because each entry in the output table corresponds to a single row of the input table.

This part of the code is magic Pandas for me.

Useful Pandas

  • groupby() method organizes rows into groups. In this case, one group per (date, title) pair.
    • Result is a Series with a multi-level index (date, title).
    • Each group has exactly one row, so sum() method just extracts that row’s value.
  • unstack() method takes the inner index level (title) and makes it into columns in a DataFrame.
    • Now each column is a song, each row is a date!
