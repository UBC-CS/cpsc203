Quick recap: Dataclasses

A dataclass bundles related data together into a custom type.

  • Attributes: data stored in the object (radius, colour)
  • Methods: functions that belong to the class (diameter)

So a dataclass is a compound data type.

  • More general than the compound data types from CPSC 103 / 110 because it allows not just attributes but also methods.
  • Reminder about the self parameter for all methods.

Useful Python: Removing Elements from a List

Lists have a method called pop(index) that removes and returns the item at that index.

  • Like append, pop mutates the list.
  • Unlike append, pop returns something other than None.

Wait a minute! Lists have methods? In fact, every type that you have already seen in Python is actually class, and most have methods. In particular, you have used list and string methods extensively (such as str.upper()).

  • So if you have other aliases for this list, then they will see the removal.
  • Why does append return None rather than the updated list? To remind you that it is mutating the list.

Why is the letter attribute “optional”?

  • It isn’t really: All (new) Bead objects will have a letter attribute, but if no value is assigned to that attribute then it will be given the default value (in this case the empty string).
  • The programmer still needs to correctly handle the default depending on context.
  • Optional in the same way that function parameters with a default are optional.

Design Strategies

  1. Identify the objects in your problem (nouns).

  2. List the data each object needs (attributes).

  3. List the operations each object supports (methods).

  4. Decide which object is responsible for what.

  5. Implement and test incrementally.

When we say “object” in this list, we mean the normal definition of the word not the programming language definition.
