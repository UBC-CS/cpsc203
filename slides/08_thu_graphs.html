Graphs

Graphs: A Model for Representing Relationships between Entities

  • Nodes or vertices represent entities.
  • Edges denote a relationship.
  • Nodes are neighbours if they share an edge.
  • How many nodes does this graph have?
  • How many edges does this graph have?
  • What are the neighbours of B?
  • Typically, nodes are labelled and edges are identified by the nodes that they connect.
    • Sometimes edges are labelled; for example, with weights
  • There are many variations; for example:
    • Edges can be directional.
    • Nodes may be disconnected.
    • There may be multiple edges between two nodes.

Graphs: Representation for Humans

A graph is a pair of lists \(G = (V,E)\).

  • The nodes / vertices \(V = \{ v_i \}\).
  • The edges are pairs of nodes \(E = \{ (v_i, v_j) \}\).

Yes, in CS we almost always use the letter \(V\) even though we often call them nodes rather than vertices.

Work through the representation:

  • \(V = \{ E, C, A, D, B, F \}\).
  • \(E = \{ (E,C), (C,A), (C,D), (A,B), (D,B), (B,F) \}\)

Does the order of the nodes / edge-pairs matter? No.

Does the order of nodes within an edge pair matter? Not if edges are bi-directional / the graph is undirected.

The nodes of this graph are labelled by their shape and colour.

  • \(V\): Courses at the university.
  • \(E\): Connect courses with a common student enrolled in both.

What is special about this labelling?

Hint: Don’t look at the three red boxes in the upper right. They look connected but they are actually overlapping edges.

Because no two courses with the same label are connected by an edge, this graph represents a feasible exam scheduling (each label is a different exam time).

Vertex labeling problem: Unfortunately, there is no efficient algorithm known for creating an optimal labelling. We could try to loop through all possible labellings, but that would be infeasibly slow.

State Machine: Is a Number Divisible by Seven?

  • Start at the circle node at the top.
  • Read the number from left to right.
  • For each digit \(d\) in the given number, follow \(d\) blue / solid edges in succession.
  • As you move from one digit to the next, follow 1 red / dashed edge.
  • If you end up back at the circle node, your number is divisible by 7.

Consider the number 3703.

In a directed graph, edges connect nodes only in one direction.

  • How do you check for divisible by 2 / 5? Check last digit.
  • Divisible by 3? Sum the digits and check if that is divisible by 3. Use recursion.
  • Divisible by 4? Check if last two digits are divisible by 4.
  • Divisible by 6? Divisible by 3 and 2.

Note that even though all nodes are connected to two blue and two red edges, one is incoming and one is outgoing.

The Stanford Bunny

  • \(V\): Points on the surface of the bunny.
  • \(E\): Connect vertices into triangles.

In a planar graph, the vertices can be placed on the plane and the graph drawn without any crossing edges.

An early example of a 3D object represented in a computer. Used extensively in academic graphics research.

  • More points were kept in regions with high curvature.
  • Edges are chosen to try to minimize the distance between the triangles and the actual surface.
  • It is then easy to colour / shade / add hair to little triangles.
  • The whole bunny is not a planar graph, but local patches of it are because it is a triangularization.
  • Note that (unlike our previous examples but like our Voronoi images) the vertices have positions in 3D space.

Complexity of Graph Algorithms

Graph Explorations

A graph \(G\) is defined by a set of vertices \(V\) and a set of edges \(E\).

  • We will often denote the size of these sets by \(|V|\) and \(|E|\).

Algorithm complexity is often described in terms of the number of vertices.

  • Actual execution time usually depends on the number of edges.
  • So how are \(|V|\) and \(|E|\) related?

Why describe complexity by \(|V|\) when it actually depends on \(|E|\)? For real problems, we often have an estimate or intuition about \(|V|\) but not \(|E|\).
